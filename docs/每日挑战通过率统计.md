# 每日挑战通过率统计后台

只统计**官方每日挑战**（不含闯关、对弈）。

## 后台页面

部署后打开：

`https://mahjong-90y.pages.dev/daily-stats.html`

（本地：`http://localhost:9002/daily-stats.html`）

口令与关卡工作台相同（`WORKBENCH_PASSWORD`），或单独配置 `DAILY_STATS_PASSWORD`。

### 指标

| 指标 | 含义 |
|------|------|
| 今日玩过 | 当日至少上报过一次开局的去重设备数 |
| 正在玩 | 近 3 分钟有开局/心跳，且尚未通关 |
| 已通过 | 当日上报通过的去重设备数 |
| 通过率 | 已通过 ÷ 玩过 |

## Cloudflare 配置

1. Pages 项目已有 Functions 即可识别 `functions/daily-stats/`
2. KV：绑定 `DAILY_STATS`（推荐），或复用已有 `LEVELS`
3. 环境变量：`WORKBENCH_PASSWORD`（或 `DAILY_STATS_PASSWORD`）
4. 可选：`DAILY_STATS_INGEST_KEY` — 配置后客户端上报需带 `X-Daily-Stats-Key`

## 客户端

`DailyChallengeAnalytics` 默认上报到：

`https://mahjong-90y.pages.dev/daily-stats/event`

调试可改：

```js
globalThis.__dailyStatsEndpoint = 'https://你的域名/daily-stats/event';
```

## 关卡资源仓库

关卡 JSON 请放到 GitHub：`hardcore-player/mahjong-resources`（`levels/`、`schedules/`）。
生成好后把文件发给助手上传即可。
